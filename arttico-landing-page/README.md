# Arttico — Landing Page

Landing page da Arttico. HTML/CSS/JS puro, sem build step.

## Rodar localmente

Abra `index.html` no navegador, ou sirva a pasta com qualquer servidor estático:

```bash
npx serve .
```

## Estrutura

- `index.html` — página
- `css/style.css` — estilos
- `js/main.js` — scripts
- `assets/` — imagens e outros arquivos estáticos
